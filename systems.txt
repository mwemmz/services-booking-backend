Services Booking App
Build Prompt: Backend & Frontend Development, Phase by Phase
1. Backend Prompts (Developer 2 — Node.js / Express / PostgreSQL)
Phase 1: Database Design & Setup
1. Design PostgreSQL schema with tables for:
   - Users (id, name, email, password_hash, phone, role, created_at)
   - Providers (id, user_id, business_name, description, category,
     is_verified, is_online, rating, location_lat, location_lng,
     service_radius, verification_documents)
   - Services (id, provider_id, name, description, price, duration,
     category, is_active)
   - Bookings (id, customer_id, provider_id, service_id, booking_time,
     status, total_amount, location_lat, location_lng, address, notes)
   - Payments (id, booking_id, amount, status, transaction_ref,
     payment_method, created_at)
   - Reviews (id, booking_id, customer_id, provider_id, rating, comment)
   - Notifications (id, user_id, type, title, body, read, created_at)
   - Locations (id, booking_id, provider_id, latitude, longitude, timestamp)
   - Categories (id, name, icon)

2. Create migration scripts with proper foreign keys, indexes, and constraints
3. Implement connection pooling and environment variable configuration
Phase 2: Authentication & User Management
1. Build authentication endpoints:
   - POST /api/auth/register — user registration with password hashing (bcrypt)
   - POST /api/auth/login — JWT token generation
   - POST /api/auth/logout — token invalidation
   - POST /api/auth/refresh-token — token refresh
   - GET /api/auth/me — get current user profile
   - PUT /api/auth/update-profile — update user details

2. Implement role-based access control (RBAC): Customer, Provider, Admin
3. Add email verification flow (optional)
4. Implement password reset functionality
5. Add rate limiting and security headers
6. Create middleware for JWT verification and role checking
Phase 3: Provider & Service Management
1. Build provider endpoints:
   - POST /api/providers/register — register as provider
   - GET /api/providers — list all providers with filters
   - GET /api/providers/:id — get provider details
   - PUT /api/providers/:id — update provider profile
   - PUT /api/providers/:id/status — toggle online/offline
   - GET /api/providers/nearby — find providers by location

2. Build service endpoints:
   - POST /api/services — create new service
   - GET /api/services — list services (with filters)
   - GET /api/services/:id — get service details
   - PUT /api/services/:id — update service
   - DELETE /api/services/:id — delete service
   - GET /api/providers/:id/services — get provider's services

3. Add validation for provider registration (Zod or Joi)
4. Implement service search and filtering
5. Add image upload for provider/service photos (Cloudinary/Firebase)
Phase 4: Booking System
1. Build booking endpoints:
   - POST /api/bookings — create new booking
   - GET /api/bookings — list bookings (with filters for role)
   - GET /api/bookings/:id — get booking details
   - PUT /api/bookings/:id/status — update booking status
   - PUT /api/bookings/:id/cancel — cancel booking
   - GET /api/customers/:id/bookings — customer's booking history
   - GET /api/providers/:id/bookings — provider's bookings

2. Implement booking workflow:
   - Customer requests service (status: pending)
   - Provider receives notification (status: assigned)
   - Provider accepts/rejects (status: accepted/rejected)
   - Provider starts service (status: in-progress)
   - Provider completes service (status: completed)
   - Customer pays (status: paid)

3. Add business logic:
   - Check provider availability before booking
   - Prevent double booking of same time slot
   - Calculate estimated arrival time
   - Set booking expiration time for pending requests
Phase 5: Real-time & Maps Integration
1. Set up Socket.IO:
   - Configure Socket.IO server with authentication
   - Create events: 'location-update', 'booking-status',
     'provider-arriving', 'notification'
   - Implement provider location broadcasting to customers
   - Add room-based communication (booking-specific rooms)

2. Build location endpoints:
   - PUT /api/locations/provider — update provider location
   - GET /api/locations/booking/:id — get booking location history
   - POST /api/locations/calculate-distance — calculate distance
   - POST /api/locations/geocode — address to coordinates

3. Integrate Google Maps APIs:
   - Directions API for route calculation
   - Distance Matrix API for ETA
   - Geocoding API for address conversion
Phase 6: Payment Integration
1. Build payment endpoints:
   - POST /api/payments/initialize — start payment
   - POST /api/payments/verify — verify payment status
   - GET /api/payments/booking/:id — get booking payments
   - POST /api/payments/webhook — handle payment gateway webhooks

2. Integrate Zambian payment gateway:
   - Implement payment initialization (Zambian payment API)
   - Add webhook handling for payment confirmation
   - Create transaction records
   - Implement refund/cancellation handling

3. Add payment calculation:
   - Service price calculation with tax
   - Discount handling
   - Payment status tracking
   - Receipt generation
Phase 7: Notifications
1. Build notification endpoints:
   - GET /api/notifications — get user notifications
   - PUT /api/notifications/:id/read — mark as read
   - PUT /api/notifications/read-all — mark all as read
   - DELETE /api/notifications/:id — delete notification

2. Implement Firebase Cloud Messaging — send push notifications for:
   - Booking confirmation
   - Booking status updates
   - Provider acceptance/rejection
   - Provider arriving
   - Payment confirmation
   - Promotional messages

3. Add email notifications (optional with Nodemailer)
4. Create in-app notification system
Phase 8: Admin Panel
1. Build admin endpoints:
   - GET /api/admin/users — user management
   - GET /api/admin/providers — provider management
   - PUT /api/admin/providers/:id/verify — verify provider
   - GET /api/admin/bookings — booking management
   - GET /api/admin/analytics — dashboard analytics
   - GET /api/admin/reports — generate reports

2. Add analytics endpoints:
   - Total bookings, revenue, users
   - Booking trends
   - Provider performance metrics
   - Customer satisfaction metrics
